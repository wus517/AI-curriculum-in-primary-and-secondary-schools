# T01 课程学习结构

状态：REVIEW（实现及隔离数据库行为测试通过，真实 MySQL 升级待 T07）。负责人：Codex 当前窗口。使用的契约版本：0.1.1。后续开发已按用户要求暂停。

## 目标和依赖

在现有课程、资源和题库上增加课程加入、课时和知识点关联。真实开发依赖 T00 契约与权限接口。课时结构查询不依赖 T02，学习进度由 T02 的 summary 单独返回，避免循环依赖。

## 文件归属

允许修改 `src/main/java/com/example/oj/learning/curriculum/`、对应测试目录、`src/main/resources/sql/migrations/V001__learning_curriculum.sql` 和本任务文件。现有 CourseController、CourseServiceImpl、DTO、VO、前端课程页由 T07 接入。

## 开发内容

1. 实现 course_enrollment、course_lesson、lesson_resource、lesson_problem 和三类知识点数据结构，使用冻结的字段和唯一键。
2. 实现自行加入课程的幂等接口、课程大纲和课时查询、课时管理及资源、题目、知识点关联接口。
3. 提供 CurriculumQueryService 与课程加入查询适配器。每次操作使用 StudentContext 和 CourseAccessService。
4. 关联资源必须属于该课程；关联题目须存在且可用。课程内知识点 ID 不接受任意其他课程的关联。
5. 去重、解除后重新绑定、课程状态变化和逻辑删除均按数据约定处理。普通用户不得借新关联接口修改题库本身。

## 验收

- 两个用户的加入记录互不混淆；重复加入和重复关联不会产生重复数据。
- 已发布、草稿、下线、删除和管理者预览的权限规则成立。
- 解除关联后重新绑定可用；错误课程资源关联被拒绝。
- 对旧课程进行增量迁移不丢数据；现有独立题库不要求加入课程。
- 服务接口和 REST 返回符合契约；为 T02 至 T04 提供可用夹具。
