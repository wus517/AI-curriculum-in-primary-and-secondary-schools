## 开发内容

1. 使用已冻结的 Java MCP SDK 和协议版本实现内部 Server 与 Client，不自行用普通 REST 伪装 MCP。
2. 实现 get_course_outline、get_my_learning_summary、list_my_submissions、get_my_submission_detail、search_course_knowledge、list_practice_candidates。
3. 实现 TutorToolGateway 的生产适配器，路由到真实 MCP Client。Server 调用公共业务服务接口，不直查 Mapper。
4. 实现逐请求短期签名凭据，验证受众、scope、过期时间和用户；共享 Client 并发时不串身份。
5. 校验 inputSchema、分页和上限，返回结构化 outputSchema；区分认证错误、业务错误、空结果和执行超时。
6. 截断和脱敏工具结果，特别是运行异常；不返回隐藏测试、标准答案和服务器路径。

## 验收

- 通过真实 Client 完成工具发现和执行，输入输出样例符合 Schema。
- 伪造、过期和错误受众凭据被拒绝；工具没有可控制目标学员的 userId 参数。
- 使用同一 Client 并发查询两个用户时，提交和进度不会串用户。
- 跨用户提交 ID、跨课程知识点、不可见课程均被服务端拒绝。
- 六个工具与真实业务服务连接后通过集成测试；Mock 结果单独列出。
