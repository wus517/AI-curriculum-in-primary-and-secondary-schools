5. 冻结 V001 至 V004 的字段和约束，确定增量迁移策略；各模块任务编写自己的实际 SQL。
6. 核对当前 Java、Spring Boot 和依赖树，记录 MCP SDK 与协议版本、模型适配器、解析库和检索基线。不可推断的费用或账户选择记为需要用户输入，但继续完成不依赖该选择的契约。
7. 冻结契约 0.1，写入 CHANGELOG，通知方式由用户决定；任务文件必须能被其他窗口直接读取。
