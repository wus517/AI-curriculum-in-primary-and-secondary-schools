## 开发内容

1. 实现本人课程会话、消息、工具审计和历史分页，保存用户来源及明确消息状态。
2. 实现 CONCEPT、HINT、REVIEW 策略，将课程片段和代码作为数据；HINT 默认逐步引导，REVIEW 使用实际提交结果。
3. 实现 TutorModelClient 适配器与受限工具循环，所有学员数据经 TutorToolGateway 获取；限制次数、长度、超时和并发。
4. 采用 POST SSE 和主手册事件，支持取消、部分回答保存、同会话互斥、clientMessageId 幂等与重启后 INTERRUPTED 恢复。
5. 校验引用与候选题 ID。资料不足区分一般解释；工具失败不补写虚构学情；模型不改变判题结果。
6. 对已展示提示写入后端 AI_HINT_USED，借用 T02 的事件接口；仅保留必要审计摘要，不记录凭据。

## 验收

- 两用户不能访问对方会话、历史、取消接口或消息流；课程失效后不可继续查询资料。
- 工具循环通过真实 MCP，另列 Mock 测试；实际模型调用需显式启用。
- SSE 中断、UTF-8、重复消息、取消、总超时、失败和恢复均有测试。
- 不存在的引用、无权限引用和编造题目 ID 不进入最终回答。
- 真实测试课程中能展示本人事实和课程出处；提示模式的行为验收有样例。
