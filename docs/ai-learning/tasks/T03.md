## 开发内容

1. 实现 document、chunk、ingestion_job，提供讲义创建、解析任务和状态查询接口。
2. 支持文本讲义、文字 PDF、PPTX；旧 PPT、扫描 PDF、无字幕视频明确为 UNSUPPORTED，不能把空文本标为 READY。
3. 按平台资源 ID 读取受控文件，保存章节或页码、来源版本和 content hash；解析任务可去重、租约恢复和有限重试。
4. 新版本完整建立后切换；旧任务晚完成不得覆盖当前版本；删除来源立即禁止搜索和引用。
5. 实现 KnowledgeSearchService 和 CitationValidationService。提供显式关键词基线，或按已记录决策实现语义检索；两者行为与配置明确区分。
6. 在候选召回前限定课程、课时与有效来源，返回前和引用打开时再次校验；引用 ID 只能来自真实片段。

## 验收

- 至少一个真实 PDF 和 PPTX 夹具能够提取文本并定位页码或幻灯片；失败与不支持类型有测试。
- 两课程语料混合时不返回无权限片段；下线、删除和替换后旧片段不可继续引用。
- 并发版本任务、重试和进程恢复不会激活错误版本。
- 检索无结果可解释，返回符合 Schema；每个引用能定位实际来源。
- 未接语义索引时，只报告关键词基线通过。
