# Agent 任务交接模板

将本模板内容填入自己的任务文件“交接记录”，不要在这个公共模板中记录个人进度。

```text
任务：Txx
状态：TODO / CLAIMED / IN_PROGRESS / REVIEW / DONE / BLOCKED
窗口标识：
工作区绝对路径：
认领时间和本次更新时间：带时区时间
使用的设计版本和契约版本：
上游任务状态与可使用的产物：

本次完成：
改动文件：准确路径，注明新增或修改
业务和接口行为：
数据库迁移：编号、执行要求、对既有数据的影响

真实验证：命令、运行环境、结果、必要输出摘要
使用 Mock 的验证：明确写出替代了什么
未运行检查：原因与影响

共享文件待集成修改：文件、修改内容、对应接口与原因
契约变更提案：原约定、新约定、受影响任务、兼容方式
阻碍和已尝试方案：
下一步：具体文件、方法或检查
仍未完成的验收项：
恢复开发需要的状态：配置名、夹具、任务状态；不要记录密钥
```

交接应足够让新窗口不读取聊天历史也能恢复。DONE 需要实际验证证据；部分实现或 Mock 通过不得填写为完整集成完成。
