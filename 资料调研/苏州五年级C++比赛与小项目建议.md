# 苏州五年级 C++ 比赛与小项目建议

整理时间：2026-04-16

> 结论先说：如果孩子现在是五年级，想在中国国内找适合的 C++ 路线，优先建议是  
> `蓝桥杯青少组 C++` > `CCF GESP C++` > `CSP-J（满 12 周岁后再考虑）`

## 1. 最适合五年级的路线怎么选

### 第一优先：蓝桥杯青少组 C++

适合原因：

- 它是面向中小学生的路线里，和 `C++` 直接相关、也更像“正式比赛”的选择。
- 蓝桥杯青少组历史上有单独的 `C++ 组` 官方规则与样题。
- 苏州本地近年有比较活跃的青少组赛事组织基础。

我查到的公开信息：

- 蓝桥杯青少组历史官方文档中，明确有“`青少年创意编程 C++ 组`”，并给出了比赛形式、知识点范围和样题。
- 苏州市教育局在 2024-08-29 发布消息：第十五届蓝桥杯人工智能青少年组现场赛在苏州举办，设有 `太仓、吴中区、苏州工业园区` 三个赛点，约 `1600 名` 中小学生参加。  
  这说明苏州本地对蓝桥杯青少组并不陌生，家长后续关注本地赛点信息会比较方便。

适合什么样的孩子：

- 已经学过 `输入输出、if、for、while、数组、函数` 的五年级孩子。
- 想“先参加一个正式比赛”，而不是只做等级考试。

建议：

- 关注官方青少组站点和苏州本地培训机构/学校发布的赛点通知。
- 如果孩子刚开始学 C++，先把下面“小项目”做 3 到 5 个，再报比赛更稳。

### 第二优先：CCF GESP C++

说明：

- `GESP` 不是“比赛”，更像权威的 `编程能力等级认证`。
- 但它非常适合作为五年级孩子的 `C++ 起步路线`，尤其在苏州本地很方便落地。

为什么适合五年级：

- 官方长期提供 `C++ 1-8 级`。
- 2026 年全年安排已经发布，节奏稳定。
- 苏州可查到不少官方考点，家长不用专门跨城折腾。

我查到的 2026 年官方时间：

- `2026-06-27`
- `2026-09-12`
- `2026-12-19`

苏州范围内可查到的 GESP 官方考点举例：

- `苏州市尚德实验小学校`
- `吴江经济技术开发区江陵实验小学`
- `江苏省吴江实验小学`
- `苏州市吴江区思贤实验小学`
- `苏州市相城区苏城外国语学校`
- `江苏省黄埭中学`
- `西交利物浦大学`
- `西交利物浦大学（太仓校区）`
- `太仓市高级中学`
- `江苏省常熟中学`
- `常熟市实验小学`
- `昆山登云科技职业学院`

适合什么样的孩子：

- 刚开始学 C++，需要一个有阶段目标的练习路线。
- 家长希望先检验基础，再决定要不要冲更难的比赛。

建议：

- 五年级如果刚学 C++，可以先冲 `GESP C++ 1-2 级`。
- 如果基础比较扎实，可以继续往 `3 级` 走，再考虑蓝桥杯青少组。

### 第三优先：CCF CSP-J

这个要特别提醒：

- `CSP-J/S` 从 `2025-02-13` 起增加年龄限制。
- 官方公告明确写了：报名参加 `CSP-J/S` 的学生，在 `当年 9 月 1 日（不含）前需满 12 周岁`。

这对五年级的影响：

- 很多五年级孩子通常还 `不到 12 周岁`，那就 **不能报名**。
- 即使年龄够了，`CSP-J` 的算法与题目难度通常也明显高于“刚学 C++”的阶段。

所以我的建议是：

- 如果孩子还没满 12 岁，不要把 `CSP-J` 当成当前主目标。
- 更适合先走 `GESP C++` 或 `蓝桥杯青少组 C++`。
- 等年龄达到要求、基础更稳之后，再转向 `CSP-J`。

## 2. 按五年级视角给一个直接建议

如果孩子现在是五年级，我会这样排：

1. 刚接触 C++：先做 3 个简单项目，顺便准备 `GESP C++ 1-2 级`
2. 已学过循环、数组、函数：开始试 `蓝桥杯青少组 C++`
3. 满 12 周岁且算法基础不错：再考虑 `CSP-J`

一句话版本：

- 想先“稳稳入门”：`GESP`
- 想尽快“参加比赛”：`蓝桥杯青少组 C++`
- 想往信息学竞赛更深入走：`CSP-J`

## 3. CSP-J 和 GESP 有什么区别

如果只用一句话来区分：

- `GESP` 更像 `分级考级`
- `CSP-J` 更像 `算法竞赛选拔的入门关`

### 家长一眼看懂版

| 对比项 | GESP C++ | CSP-J |
| --- | --- | --- |
| 性质 | 编程能力等级认证 | 信息学竞赛路线中的认证/选拔 |
| 更像什么 | 考级 | 竞赛 |
| 适合谁起步 | 刚学 C++ 的孩子 | 已有一定算法基础的孩子 |
| 难度节奏 | 1 到 8 级，循序渐进 | 整体更偏算法，起点更高 |
| 年龄限制 | 我查到的官方公开资料里，未见类似 `12 周岁` 的硬门槛 | `2025-02-13` 起明确要求：当年 `9 月 1 日前满 12 周岁` |
| 形式 | 直接报对应级别参加认证 | `两轮制`，第一轮后再进第二轮 |
| 语言路线 | 官方长期提供 `图形化 / Python / C++` | 准备信息学竞赛路线时通常按 `C++` 学 |
| 对五年级是否友好 | 很友好，适合做阶段目标 | 取决于年龄和基础，很多五年级孩子暂时不适合 |
| 和升阶路线的关系 | 高等级可衔接 CSP-J/S 第一轮免认证资格申请 | 更接近正式信息学竞赛路线 |

### 更实用的理解

- `GESP` 解决的是“孩子现在学到什么水平了”。
- `CSP-J` 更关注“孩子能不能做算法题、能不能进入竞赛路线”。
- `GESP` 适合拿来建立节奏感和成就感。
- `CSP-J` 更适合作为后续目标，而不是很多五年级孩子一开始就直冲的目标。

### 两者能不能连起来

可以，而且官方有衔接规则。

- `GESP C++ 7 级` 成绩达到一定标准后，可申请 `CSP-J` 第一轮免认证资格。
- `GESP C++ 8 级` 成绩达到更高标准后，可申请 `CSP-J` 或 `CSP-S` 第一轮免认证资格。
- 但即使满足这个衔接条件，`CSP-J/S` 的年龄要求仍然要单独满足。

### 对五年级的直接建议

- 刚开始学：先走 `GESP C++ 1-2 级`
- 已经会循环、数组、函数：继续做项目，同时准备 `GESP 2-3 级` 或 `蓝桥杯青少组 C++`
- 满 `12` 周岁且算法基础不错：再把 `CSP-J` 当成下一阶段目标

## 4. 简单易上手的 C++ 小项目

下面这些项目都比较适合五年级，重点是“能做完、能改功能、能产生成就感”。

### 项目 1：猜数字游戏

功能：

- 电脑随机生成一个 1 到 100 的数字
- 用户不断输入数字
- 程序提示“大了”还是“小了”
- 猜中后显示一共猜了几次

会用到：

- `rand`
- `if`
- `while`
- 计数变量

难度：`很低`  
推荐指数：`5/5`

### 项目 2：四则运算练习器

功能：

- 随机出加减乘除题
- 用户输入答案
- 程序自动判断对错
- 最后统计得分

会用到：

- 随机数
- 条件判断
- 循环
- 分数统计

难度：`很低`  
推荐指数：`5/5`

### 项目 3：班级点名器

功能：

- 先输入若干同学名字
- 随机抽一个名字
- 可以设置“今天不重复抽到”

会用到：

- 数组或 `vector`
- 字符串
- 随机数

难度：`低`  
推荐指数：`5/5`

### 项目 4：成绩统计小助手

功能：

- 输入语文、数学、英语等成绩
- 自动算总分、平均分、最高分、最低分
- 判断优秀/良好/及格

会用到：

- 数组
- 循环
- 比较大小
- 简单函数

难度：`低`  
推荐指数：`4/5`

### 项目 5：苏州景点问答小游戏

功能：

- 设计 5 到 10 道关于苏州园林、昆曲、平江路、拙政园的小题目
- 用户答题后自动计分
- 最后给出“文化小达人”等评价

会用到：

- 字符串
- 判断
- 分数统计

优点：

- 有地方特色，孩子通常更有兴趣
- 很适合做成比赛前的“小作品”

难度：`低`  
推荐指数：`4/5`

### 项目 6：简易迷宫游戏（文字版）

功能：

- 用字符画一个小迷宫
- 玩家输入 `W/A/S/D` 控制移动
- 走到出口就胜利

会用到：

- 二维数组
- 坐标
- 判断边界
- 循环刷新

难度：`中等`  
推荐指数：`5/5`

### 项目 7：宠物养成小游戏

功能：

- 有一个小宠物
- 可以喂食、睡觉、玩耍
- 宠物有“体力、心情、饱腹值”
- 如果长时间不照顾，状态会下降

会用到：

- 结构体
- 菜单循环
- 多个变量状态联动

难度：`中等`  
推荐指数：`4/5`

### 项目 8：简易商品收银台

功能：

- 输入商品名称和价格
- 自动累计金额
- 支持“打折”“满减”
- 输出小票总价

会用到：

- 字符串
- 数组或结构体
- 条件判断
- 小数计算

难度：`中等`  
推荐指数：`4/5`

## 5. 再进阶一点的 C++ 小项目

如果你觉得上面那一组偏基础，这一组更适合“已经会基本语法，想做得更像一个完整作品”的孩子。

这些项目的定位是：

- 比前面那组更有挑战
- 还没到正式竞赛题的难度
- 很适合往 `GESP 2-4 级` 或 `蓝桥杯青少组 C++` 之前过渡

### 项目 9：学生信息管理系统

功能：

- 录入学生姓名、学号、语数英成绩
- 支持查询、修改、删除
- 可以按总分从高到低排序
- 输出“班级前 3 名”

会用到：

- `struct`
- `vector`
- 函数拆分
- 查找与排序

为什么值得做：

- 它已经很像一个真正的小系统了
- 能把“数组 + 结构体 + 菜单”连起来用

难度：`中等偏上`  
推荐指数：`5/5`

### 项目 10：图书借阅管理器

功能：

- 录入图书名称、编号、是否借出
- 支持借书、还书、查询
- 可以查看“当前已借出图书”列表

会用到：

- 结构体
- 字符串
- 条件判断
- 菜单循环

为什么值得做：

- 和学校生活贴近，孩子比较容易理解
- 很适合练“状态变化”这件事

难度：`中等`  
推荐指数：`4/5`

### 项目 11：单词卡片复习器

功能：

- 预先存一组英文单词和中文意思
- 程序随机出题
- 用户输入答案后判断对错
- 自动记录错题次数

会用到：

- 字符串
- 随机数
- 结构体或并行数组
- 统计与记录

为什么值得做：

- 比普通问答小游戏更实用
- 能练到“数据记录”和“重复练习”逻辑

难度：`中等`  
推荐指数：`4/5`

### 项目 12：回合制战斗小游戏

功能：

- 角色和怪物都有生命值、攻击力、防御力
- 每回合可以选择“普通攻击、技能、回复”
- 支持暴击或闪避这类随机事件
- 一局结束后输出战斗记录

会用到：

- 多个函数配合
- 随机数
- 变量状态联动
- 菜单输入

为什么值得做：

- 趣味性很强，孩子通常愿意反复改功能
- 很适合练“规则设计”和“状态更新”

难度：`中等偏上`  
推荐指数：`5/5`

### 项目 13：关键词统计器

功能：

- 输入一段文字
- 统计某些关键词出现了多少次
- 比如统计“苏州”“园林”“小学生”“编程”等词出现次数
- 最后输出出现次数最多的词

会用到：

- 字符串处理
- 循环
- 条件判断
- 计数数组

为什么值得做：

- 比简单输入输出更接近真实应用
- 能开始接触一点“文本处理”思维

难度：`中等`  
推荐指数：`4/5`

### 项目 14：排行榜系统

功能：

- 录入多个玩家姓名和分数
- 按分数自动排序
- 支持插入新成绩后重新排名
- 显示“第几名”和并列情况

会用到：

- 数组或 `vector`
- 结构体
- 排序
- 遍历输出

为什么值得做：

- 这是很多比赛题和管理题都会用到的基础模型
- 练好之后，对后面刷题也有帮助

难度：`中等偏上`  
推荐指数：`5/5`

### 项目 15：数独合法性检查器

功能：

- 输入一个 `9 x 9` 数独盘面
- 判断每一行、每一列是否重复
- 判断每个 `3 x 3` 宫格是否重复
- 输出“合法 / 不合法”

会用到：

- 二维数组
- 多重循环
- 下标与范围判断
- 逻辑检查

为什么值得做：

- 已经开始有一点“算法题味道”
- 但它还是一个很完整、很清楚的小项目

难度：`中等偏上`  
推荐指数：`5/5`

## 6. 一个务实的学习顺序

建议按下面顺序推进：

1. `输入输出 -> 判断 -> 循环`
2. `数组 -> 字符串 -> 函数`
3. `做 3~5 个小项目`
4. `做 2~3 个进阶项目`
5. `尝试 GESP C++ 1-2 级`
6. `尝试蓝桥杯青少组 C++`
7. `年龄和基础都合适后，再考虑 CSP-J`
