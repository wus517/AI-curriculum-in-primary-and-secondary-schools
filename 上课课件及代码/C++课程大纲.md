# C++课程大纲

## 一、基础语法

### 1. 基本概念
- 程序的编译与运行（Dev-C++ / 在线编译器的使用）
- `#include`、`using namespace std`、`main` 函数的固定框架
- 注释

### 2. 变量与数据类型
- 变量的定义与命名规则
- 常用数据类型：`int`、`double`、`char`、`bool`
- 常量（`const`）
- 类型转换（隐式转换、强制转换简介）

### 3. 运算符
- 算术运算符（`+` `-` `*` `/` `%`）
- 赋值运算符（`=`、`+=` 等）
- 比较运算符（`==` `!=` `>` `<` `>=` `<=`）
- 逻辑运算符（`&&` `||` `!`）

### 4. 输入与输出
- `cout` 输出与格式控制（`endl`、换行）
- `cin` 输入
- 多变量输入输出

### 5. 分支结构
- `if` / `if-else` / `if-else if-else`
- 嵌套 `if`
- `switch-case`（简单了解）

### 6. 循环结构
- `while` 循环
- `for` 循环
- 循环嵌套
- `break` 与 `continue`
