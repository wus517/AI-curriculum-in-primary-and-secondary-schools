# CSP分支循环专项练习题

## 选择题

1. 以下代码的输出结果是？

   ```c++
   int a = 3, b = 5;
   if (a > b) {
       cout << a;
   } else {
       cout << b;
   }
   ```

   A. 3

   B. 5

   C. 35

   D. 编译错误

2. 以下代码的输出结果是？

   ```c++
   int x = 2;
   switch (x) {
       case 1: cout << "1";
       case 2: cout << "2";
       case 3: cout << "3";
       default: cout << "4";
   }
   ```

   A. 2

   B. 23

   C. 234

   D. 4

3. `for (int i = 1; i <= 5; i++)` 循环体的执行次数是？

   A. 4

   B. 5

   C. 6

   D. 无限循环

4. 关于 `while` 和 `do-while` 循环，以下说法正确的是？

   A. `while` 循环至少执行一次

   B. `do-while` 循环至少执行一次

   C. 两者没有区别

   D. `do-while` 循环先判断条件再执行

5. 以下代码的输出结果是？

   ```c++
   int i = 0;
   while (i < 5) {
       if (i == 3) break;
       cout << i;
       i++;
   }
   ```

   A. 012

   B. 0123

   C. 01234

   D. 无限循环

6. 以下代码的输出结果是？

   ```c++
   int i = 0;

       cout << i;
   }
   ```

   A. 12345

   B. 1245

   C. 01245

   D. 01234

8. 嵌套循环 `for (int i = 0; i < 3; i++) for (int j = 0; j < 2; j++)` 内层循环体总共执行几次？

## 程序设计题

### 1. 奇偶判断

题目：输入一个整数，判断它是奇数还是偶数，是奇数输出`odd`，偶数输出`even`。

考点：`if-else` 分支、取余运算

### 2. 1~n求和

题目：输入正整数n，计算1+2+3+…+n的和。

考点：`for`循环、累加器

### 3. 分数等级

题目：输入0~100的分数，≥90为A，≥80为B，≥60为C，<60为D。

考点：多分支`if-else if`

### 4. 水仙花数

题目：输出所有**三位数水仙花数**（各位立方和=本身，如153=1³+5³+3³）。

考点：循环+分支、数位拆分

### 5. 质数判断

题目：输入一个数，判断是否为质数（只能被1和自身整除）。

考点：循环+分支、边界判断

### 6. 九九乘法表

题目：输出正序九九乘法表（下三角）。

考点：**双层for循环嵌套**（CSP核心）

### 7. 统计字符

题目：输入一行字符，统计**字母、数字、空格、其他字符**的数量。

考点：`while`循环、ASCII判断

### 8. 求最大公约数

题目：输入两个数，求最大公约数（辗转相除法）。

考点：`while`循环、数学逻辑

### 9. 【CSP-J 2020 入门】 整除问题

题目：输入n，求1~n中能被3或5整除的数的和。

考点：循环+分支、条件判断

### 10. 【CSP-J 基础真题】 分段函数

题目：

```
x<1 → f(x)=x

1≤x<10 → f(x)=2x-1

x≥10 → f(x)=3x-11
```

输入x，输出f(x)

考点：多分支判断
