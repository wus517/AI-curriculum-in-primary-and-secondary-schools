# CSP分支循环专项练习题（答案+解析）

## 选择题

1、B

```c++
int a = 3, b = 5;
if (a > b) {
    cout << a;
} else {
    cout << b;
}
```

核心考点

`if-else` 双分支语句的执行逻辑

详细解析

1. 代码定义变量`a=3`、`b=5`，首先判断`if`的条件`a > b`（即`3>5`），该条件不成立。
2. `if-else`的两个分支是互斥关系，`if`条件不成立时，程序会跳过`if`代码块，直接执行`else`代码块，输出`b`的值`5`。
3. 错误选项说明：
   - A：仅当`a>b`条件成立时才会输出`3`，不符合当前逻辑；
   - C：`if-else`分支不可能同时执行，不会输出两个值；
   - D：代码语法完全符合 C++ 规范，不会出现编译错误。

2、C

题目代码

```c++
int x = 2;
switch (x) {
    case 1: cout << "1";
    case 2: cout << "2";
    case 3: cout << "3";
    default: cout << "4";
}
```

核心考点

`switch`语句的**case 穿透特性**

详细解析

1. `switch`会匹配与变量`x=2`相等的`case`分支，成功匹配`case 2`，执行`cout << "2"`。
2. 该`case`分支没有添加`break`语句，会触发**case 穿透**：程序不会跳出`switch`，会继续顺序执行后续所有`case`和`default`的代码，依次输出`3`和`4`。
3. 最终输出结果为`234`。
4. 错误选项说明：
   - A：仅当`case 2`末尾添加`break`时，才会只输出`2`；
   - B：仅当`case 3`末尾添加`break`时，才会输出`23`；
   - D：仅当没有任何`case`匹配`x`的值时，才会只执行`default`输出`4`。

3、B

核心考点

`for`循环的执行流程与执行次数计算

详细解析

1. `for`循环的执行顺序为：初始化语句→循环条件判断→执行循环体→执行更新语句→再次判断循环条件，以此循环。

2. 本题中，初始化

   ```
   i=1
   ```

   ，循环条件为

   ```
   i<=5
   ```

   ，每次循环后

   ```
   i++
   ```

   - 满足条件的`i`值为`1、2、3、4、5`，共 5 个值，因此循环体执行 5 次。

3. 错误选项说明：

   - A：对应循环条件为`i<5`的执行次数；
   - C：对应初始化`i=0`、循环条件`i<=5`的执行次数；
   - D：仅当循环条件永远为真时才会出现无限循环，本题条件会在`i=6`时不成立，循环终止。

4、B

核心考点

`while`循环与`do-while`循环的核心区别

详细解析

1. `while`循环的执行逻辑：**先判断循环条件，条件成立才执行循环体**。如果初始条件就不成立，循环体一次都不会执行。
2. `do-while`循环的执行逻辑：**先执行一次循环体，再判断循环条件**。无论初始条件是否成立，循环体至少会执行 1 次。
3. 错误选项说明：
   - A：说法完全相反，`while`循环可能一次都不执行；
   - C：两者的执行顺序、执行次数的边界场景有明显区别；
   - D：说法完全相反，`do-while`循环是先执行循环体，再判断条件。

5、A

```c++
int i = 0;
while (i < 5) {
    if (i == 3) break;
    cout << i;
    i++;
}
```

核心考点

循环中`break`关键字的作用

详细解析

1. `break`关键字的作用是：**直接终止当前整个循环，跳出循环体**。
2. 代码执行流程：
   - `i=0`：`i<5`成立，`i!=3`，输出`0`，`i`自增为 1；
   - `i=1`：`i<5`成立，`i!=3`，输出`1`，`i`自增为 2；
   - `i=2`：`i<5`成立，`i!=3`，输出`2`，`i`自增为 3；
   - `i=3`：`i<5`成立，`i==3`触发`break`，循环直接终止，不再执行后续的输出和自增操作。
3. 最终输出结果为`012`。
4. 错误选项说明：
   - B：仅当`break`语句放在`cout << i`之后时，才会输出`0123`；
   - C：对应没有`break`语句的执行结果；
   - D：仅当循环中没有`i++`的自增操作时，才会出现无限循环。

6、B

```c++
int i = 0;
while (i < 5) {
    i++;
    if (i == 3) continue;
    cout << i;
}
```

核心考点

循环中`continue`关键字的作用

详细解析

1. `continue`关键字的作用是：**跳过本次循环剩余的语句，直接进入下一次循环的条件判断**，不会终止整个循环。

2. 代码执行流程：

   - `i=0`：`i<5`成立，`i`自增为 1，`i!=3`，输出`1`；
   - `i=1`：`i<5`成立，`i`自增为 2，`i!=3`，输出`2`；
   - `i=2`：`i<5`成立，`i`自增为 3，`i==3`触发`continue`，跳过后续的`cout`，直接进入下一次循环判断；
   - `i=3`：`i<5`成立，`i`自增为 4，`i!=3`，输出`4`；
   - `i=4`：`i<5`成立，`i`自增为 5，`i!=3`，输出`5`；
   - `i=5`：`i<5`不成立，循环终止。

   

3. 最终输出结果为`1245`。

4. 错误选项说明：

   - A：对应没有`continue`语句的执行结果；
   - C、D：代码中`i++`在`cout`之前，初始`i=0`会先自增为 1，不会输出`0`。

7、B

```c++
int score = 85;
if (score >= 90) {
    cout << "A";
} else if (score >= 80) {
    cout << "B";
} else if (score >= 60) {
    cout << "C";
} else {
    cout << "D";
}
```

核心考点

`if-else if`多分支语句的匹配逻辑

详细解析

1. `if-else if`多分支的执行逻辑是：**从上到下依次判断条件，匹配到第一个成立的条件后，执行对应代码块，后续所有分支都会被跳过，不再判断**。
2. 代码执行流程：
   - 首先判断`score >= 90`：`85>=90`不成立，跳过该分支；
   - 接着判断`score >= 80`：`85>=80`成立，执行该分支输出`B`，后续的分支不再执行。
3. 错误选项说明：
   - A：仅当`score>=90`时才会输出`A`；
   - C：仅当`score<80且>=60`时才会输出`C`；
   - D：仅当`score<60`时才会输出`D`。

8、D

核心考点

嵌套循环的执行次数计算

详细解析

1. 嵌套循环的执行逻辑是：外层循环每执行 1 次，内层循环会完整执行全部次数。
2. 次数计算：
   - 外层循环：`i`从 0 到 2，共执行 3 次；
   - 内层循环：`j`从 0 到 1，每次外层循环都会执行 2 次；
   - 内层循环总执行次数 = 外层循环次数 × 单次外层循环对应的内层循环次数 = 3×2=6 次。
3. 错误选项说明：
   - A：仅为内层循环单次的执行次数；
   - B：仅为外层循环的执行次数；
   - C：为两层循环的次数相加，不符合嵌套循环的执行逻辑。

9、B

```c++
int sum = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        sum += i;
    }
}
cout << sum;
```

核心考点

循环中的条件筛选与累加运算

详细解析

1. 代码的核心逻辑是：遍历 1 到 10 的所有整数，筛选出其中的偶数，累加到`sum`中。
2. 执行流程：
   - 1 到 10 中的偶数为`2、4、6、8、10`；
   - 累加计算：`2+4+6+8+10=30`，最终输出`sum`的值为 30。
3. 错误选项说明：
   - A：对应 1 到 10 的奇数和（1+3+5+7+9=25）；
   - C：无对应符合逻辑的计算结果；
   - D：对应 1 到 10 的所有整数的和（1+2+...+10=55）。

10、C

```c++
for (int i = 0; i < 3; i++) {
    cout << i;
}
cout << i;
```

核心考点

C++ 中 for 循环初始化变量的作用域规则

详细解析

1. C++ 标准规定：在`for`循环的初始化语句中定义的变量，**作用域仅限于 for 循环内部**，循环结束后该变量会被销毁，生命周期结束。
2. 本题中，变量`i`是在 for 循环的初始化语句中定义的，在循环结束后，循环外的`cout << i`尝试访问已经销毁的变量`i`，编译器会报 “未定义标识符” 的错误，因此代码无法通过编译。
3. 错误选项说明：
   - A、B：代码无法通过编译，不会有运行后的输出结果；
   - D：运行时错误是代码编译通过后，运行时出现的问题，本题在编译阶段就会报错，不属于运行时错误。

## 程序设计题

### 1. 奇偶判断

考点解析：核心是利用取余运算`n%2`判断奇偶，余数为0则为偶数，否则为奇数，考查`if-else`分支的基础用法。

参考代码：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) cout << "even";
    else cout << "odd";
    return 0;
}
    
```

### 2. 1~n求和

考点解析：用累加器`sum`存储总和，通过`for`循环遍历1到n，每次将当前数累加到sum中，考查循环与累加器的结合。

参考代码：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, sum = 0;
    cin >> n;
    for (int i = 1; i <= n; i++) sum += i;
    cout << sum;
    return 0;
}
    
```

### 4. 水仙花数

考点解析：核心是数位拆分（百位、十位、个位），通过循环遍历所有三位数，结合分支判断是否满足水仙花数条件，考查循环与数位运算的结合。

参考代码：

```cpp
#include <iostream>
using namespace std;
int main() {
    for (int i = 100; i <= 999; i++) {
        int a = i / 100;    // 百位
        int b = i / 10 % 10;// 十位
        int c = i % 10;     // 个位
        if (a*a*a + b*b*b + c*c*c == i) cout << i << " ";
    }
    return 0;
}
    
```

## 二、进阶练习题

### 5. 质数判断

考点解析：质数的边界条件（小于2的数不是质数），循环判断范围优化为`i*i <= n`（减少循环次数），用flag标记是否为质数，考查循环边界与逻辑判断。

参考代码：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, flag = 1;
    cin >> n;
    if (n < 2) flag = 0;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) { flag = 0; break; }
    }
    if (flag) cout << "yes";
    else cout << "no";
    return 0;
}
    
```

### 6. 九九乘法表

考点解析：双层for循环嵌套，外层控制行数（1-9），内层控制每行的列数（1-当前行数），考查嵌套循环的逻辑控制。

参考代码：

```cpp
#include <iostream>
using namespace std;
int main() {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            cout << j << "*" << i << "=" << i*j << "\t";
        }
        cout << endl;
    }
    return 0;
}
    
```

### 7. 统计字符

考点解析：用`while`循环读取字符（直到换行），通过ASCII码范围判断字符类型，用四个变量分别统计各类字符数量，考查while循环与字符判断。

参考代码：

```cpp
#include <iostream>
using namespace std;
int main() {
    char c;
    int a=0,b=0,d=0,e=0;
    while((c=getchar())!='\n'){
        if((c>='a'&&c<='z')||(c>='A'&&c<='Z'))a++;
        else if(c>='0'&&c<='9')b++;
        else if(c==' ')d++;
        else e++;
    }
    cout<<a<<" "<<b<<" "<<d<<" "<<e;
    return 0;
}
    
```

### 8. 求最大公约数

考点解析：利用辗转相除法（欧几里得算法），核心逻辑为“大数除以小数，余数作为新的小数，原小数作为新的大数，直到余数为0”，考查while循环的逻辑应用。

参考代码：

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    while (b != 0) {
        int temp = a % b;
        a = b;
        b = temp;
    }
    cout << a;
    return 0;
}
    
```

### 9. 【CSP-J 2020 入门】 整除问题

考点解析：循环遍历1到n，用`i%3==0 || i%5==0`判断是否符合条件，累加符合条件的数，考查循环与逻辑或运算的结合。

```cpp

}
    
```

### 10. 【CSP-J 基础真题】 分段函数

考点解析：根据x的不同范围，执行不同的函数计算，注意判断顺序（从左到右，覆盖所有情况），考查多分支判断的实际应用。

```cpp
#include <iostream>
using namespace std;
int main() {
    int x;
    cin >> x;

```
